# 障碍、四阶楼梯接下坡与多楼层

## 几何与未知值

四个踢面各 0.16 m，总升高 0.64 m。四个完整踏面各 0.30 m 时名义水平长度 1.20 m，但现场应确认顶层平台如何计入。楼梯宽 1.20 m。斜坡接在上楼之后，下到原地面；坡长、坡宽、平台长度、缝隙和连接角未知，保留 configs/mission.template.yaml 中的 null。

坡水平投影 L 时坡角 atan(0.64/L)，若给的是斜面长度 S 则 asin(0.64/S)。不能混用两种长度，更不能默认雷达安装倾角就是坡角。

## 先验收底层，再配置导航

同一 MoE 分别测试：平地速度/停止、16 cm 上阶、四阶连续上楼、前后足跨越坡顶、下坡、坡底回平地与停止。使用物理仿真时必须有真实的足地接触和 MoE 控制，运动学模型沿 z 轨迹移动不构成爬楼能力验证。

再组合任务：平地接近 → 对准楼梯中心线 → 上楼 → 顶部支撑过渡 → 下坡 → 出口平地 → 停车。顶部没有足够平台时，把它当连续支撑转换处理，不能要求机器人在很窄的脊顶停住或原地旋转。坡顶身体/腿的净空、前后足支撑不同步都需要底层验证。

## 路线输入

首版建议 navi_mode=2，用同一定位/坐标适配链示教机身中心路线，记录到 sources/scan/tools/keypoint.yaml：

```yaml
fsm:
  waypoint_num: 2
  waypoint0_x: 0.0
  waypoint0_y: 0.0
  waypoint0_z: 0.4
  waypoint1_x: 1.0
  waypoint1_y: 0.0
  waypoint1_z: 0.4
```

**上面仅演示格式，不代表你的路线、机身高度或可运行场地，不作为默认文件提交。** 模式 2 输入的是机身参考位置，z 不应写成地面高度。按楼梯入口、上楼段、顶部转换和坡底保留关键点，真实值来自当前 nav_odom。

模式 3 订阅 /initial_path（nav_msgs/Path），该固定版本 pathCallback 会给路径 z 加 body_height，所以应输入支撑面高度；若你的路径是机身中心轨迹，要显式修改这处约定并记录补丁。不要重复加高。

源码另有 `constexpr double min_dist = 0.5`，可能删掉 0.30 m 踏面上的中间点。后续把间距做成参数，离线比较 0.15–0.20 m，同时强制保留楼梯/坡顶/坡底关键点。当前仓库记录了修改需求，尚未对上游实现该补丁；稠密点本身也不保证支撑有效。

## 局部规划约束

SCAN 的三维轨迹不是足端轨迹。高度路径不应随意“抬高到不碰撞就算可走”，必须与 MoE 的真实支撑姿态和机身参考定义一致。

| 配置 | 初始处理 |
|---|---|
| grid_map.resolution | 可先保留 0.05 m，再检查 16 cm 踢面是否被正确表达 |
| double_cylinder_radius/offset | 根据带载机身几何和姿态包络验证，不能缩小到穿过真实障碍 |
| obstacles_inflation_z_up/down | 需结合机身/腿部净空验证，不能单纯削薄膨胀强行爬楼 |
| manager/optimization/max_vel 与跟踪器限速 | 保持一致，并按底层已验收的上楼/下坡速度分别限制 |
| max_vy、转向策略 | 楼梯/坡面优先沿中线，限制横移和急转 |
| 近场滤除/局部地图范围 | 确认踏面/坡顶没有被 blind 或机壳滤除误删 |

需要任务层维护中心线走廊和边缘净空。只有几个 xyz 航点时，局部优化可能切角绕开楼梯、走到边缘或试图从不支持的空间通过；必须有支撑/可通行性约束与任务失败处理。

障碍物应先分为允许踩过的小障碍、必须绕行的不可通行障碍、禁止进入的落差/边缘。MoE 能越障不意味着规划器能自动识别所有可越障物体。不要通过删除障碍点或全局降低膨胀把未知障碍判为可通行。

## 多楼层

建立三维拓扑图：楼层区域、楼梯入口/出口、休息平台为节点；楼梯或走廊为边，带方向、坡度、宽度和能力条件。任务管理器选楼层路线，逐段交给 SCAN，维护到达、取消、失败、重新定位与模式切换。

统一 W/map 或显式注册各楼层子地图，维持地图版本与 floor_id。上下两层 XY 重叠不能合并到单层二维 costmap。局部高程图可辅助当前楼层支撑判断，但单个普通 2.5D 高度单元不能同时表示多层重叠表面。

Elevator-LIO 的电梯功能针对非惯性电梯运动；当前只有楼梯/坡道时关闭 elevator mode。TravExplorer 是架构参考，交接时不能假设其完整代码已发布；确认发布后再评估，不把它作为当前可执行依赖。

## 验收记录

每段保存模型 SHA、环境几何、载荷/摩擦、命令范围、真实机身轨迹、最小边缘距离、定位连续性、碰撞/失足/接管、停止行为及视频。完整任务至少覆盖起始偏差、上/下楼方向需求、不同地图起点和网络/定位失效。通过某一固定场景只说明该范围通过，不能扩大为任意多楼层导航。
